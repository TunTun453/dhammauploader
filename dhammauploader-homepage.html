From a Drive folder to YouTube, in one run.

DhammaUploader is a small personal tool that takes finished dhamma (Buddhist teaching) videos from a Google Drive folder named ပြီးစီး and uploads them to the YouTube channel Dhammaအလင်း as Unlisted videos, ready for the channel owner to review and publish.

  • Free — no cost, no payment
  • Personal — one user, the owner
  • On demand — runs in Google Colab
  • Unlisted first — nothing goes public automatically

What it does

DhammaUploader moves the owner's own finished dhamma videos from Google Drive to his own YouTube channel. The owner prepares each video himself, places the finished file in a Drive folder called ပြီးစီး (“finished”), and runs the tool. The tool reads the video from that folder and uploads it to the channel Dhammaအလင်း with the privacy status set to Unlisted. The owner then checks the video on YouTube and decides himself whether and when to make it public.

That is the whole job of the tool. It does not edit videos, does not manage comments or other channel content, and does not post anything publicly on its own.

How it works

  1. The owner adds a finished video The completed MP4 file is placed in the ပြီးစီး folder in the owner's own Google Drive.
  2. The owner starts the tool DhammaUploader runs as a notebook in Google Colab, started manually by the owner each time. There is no server and nothing runs in the background.
  3. The tool reads the folder Using the Google Drive API in read-only mode, the tool lists and downloads the video files the owner placed in the ပြီးစီး folder — nothing else in Drive is touched.
  4. The tool uploads to YouTube Using the YouTube Data API v3, the tool uploads the video to the owner's own channel, Dhammaအလင်း, with the privacy status set to Unlisted.
  5. The owner reviews and publishes The owner watches the Unlisted video, sets the title and details, and flips it to public himself when he is satisfied. Publishing is always a manual decision.

Who can use it, and what it can access

DhammaUploader is a private, single-user tool. It is used only by its owner, Tun Tun, and only with his own Google account. It is not offered to the public, has no sign-up, no other users, and no way for anyone else to run it or connect their accounts.

YouTube Data API v3 Uploads videos to the owner's own channel (Dhammaအလင်း) as Unlisted. No other channel is accessed.
Google Drive API (read-only) Reads the video files in the owner's own ပြီးစီး folder so they can be uploaded. The tool never edits, moves, or deletes Drive files.

Access is granted by the owner through Google's standard OAuth sign-in, is limited to the permissions above, and can be revoked by the owner at any time in his Google Account settings.

Privacy Policy

Last updated: 21 November 2026

This policy describes how DhammaUploader (“the tool”) handles information. The tool is operated by Tun Tun (tun522526@gmail.com) as a personal, non-commercial project.

Who uses the tool

The tool has exactly one user: its owner. It is not a public service. It does not offer accounts, sign-ups, or access to any other person, and it never signs in to, reads, or uploads to any Google or YouTube account other than the owner's own.

Information the tool accesses

  • Google Drive (read-only): the names and contents of video files that the owner himself placed in his ပြီးစီး folder, so those files can be uploaded. The tool does not modify or delete anything in Drive.
  • YouTube: permission to upload videos to the owner's own channel, Dhammaအလင်း, and to set their privacy status to Unlisted.

The tool does not collect names, email addresses, contacts, location, browsing history, or any other personal information about any person.

How the information is used

Accessed files are used for one purpose only: transferring the owner's own videos from his Google Drive folder to his own YouTube channel as Unlisted uploads. Nothing is used for advertising, profiling, analytics, or any other purpose.

Sharing

No data accessed by the tool is sold, rented, shared, or transferred to any third party. Video files pass directly between the owner's Google Drive, the Google Colab session the owner is running, and his YouTube channel, using Google's own APIs.

Storage and retention

The tool has no server and no database, and it stores nothing outside the owner's own Google account. It runs only when the owner starts it in Google Colab, and the temporary working copies of video files exist only inside that Colab session and disappear when the session ends. The OAuth credentials the tool uses are kept within the owner's own Google account and Drive, under the owner's control.

Revoking access

The owner can revoke the tool's access at any time from the “Third-party access” section of his Google Account settings, which immediately stops the tool from reaching Drive and YouTube.

Google API Services User Data Policy

DhammaUploader's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
