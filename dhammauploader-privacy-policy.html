About DhammaUploader

DhammaUploader is a free personal tool, run by its owner only. It is not a public service, not a business, and it has no other users.

Its single job is to move the owner's own dhamma (Buddhist teaching) videos from the owner's Google Drive to the owner's own YouTube channel, so the talks can be shared as dhamma dana (a free gift of teaching).

How it works

  1. The owner places finished videos in a Google Drive folder named ပြီးစီး (“finished”).
  2. The tool runs in Google Colab, in the owner's own account, only when the owner starts it.
  3. It downloads a video from that Drive folder and uploads it to the owner's own YouTube channel.
  4. Every upload is set to Unlisted. The owner reviews each video and decides himself whether to make it public.

There is no background service: when the owner is not running it, DhammaUploader does nothing at all.

Privacy Policy

Effective date: 21 November 2026

Owner: Tun Tun · tun522526@gmail.com

This policy explains exactly what DhammaUploader accesses, what it does with that access, and what it never does. Because the tool is used by its owner alone, on the owner's own accounts and files, it handles no one else's data.

1. What the tool accesses

DhammaUploader uses two Google APIs, each with the narrowest permission it needs:

YouTube — YouTube Data API v3

Scope: youtube.upload

Used only to upload videos to the owner's own YouTube channel, with each video set to Unlisted. The tool does not read, change, or delete anything else on YouTube — no other channels, no comments, no playlists, no account settings.

Google Drive — Drive API

Scope: drive.readonly (read-only)

Used only to list and download the owner's own video files from the owner's Drive folder named ပြီးစီး. The read-only scope means the tool cannot modify, share, move, or delete anything in Drive.

2. How video files move

Video files travel along one path only: from the owner's Google Drive, through Google Colab (running in the owner's account), to the owner's YouTube channel. Files are never sent to any other service, server, or person.

3. The authorization token

The Google authorization token the tool uses is stored only in a private folder inside the owner's own Google Drive. It is not shared with anyone and is never sent anywhere else.

4. What the tool does not do

  • It collects no personal data.
  • It stores no personal data, beyond the owner's own token described above.
  • It sells no data, and shares no data with anyone.
  • It has no other users, and tracks no users.
  • It runs no background service — it works only while the owner runs it in Colab.
  • It shows no ads.

5. Revoking access

The owner can revoke DhammaUploader's access at any time from the security settings of his Google account (Google Account → Security → Third-party access), and can delete the stored token file from his Drive. Once revoked or deleted, the tool can no longer access YouTube or Drive until the owner authorizes it again.

6. Changes to this policy

If the tool's access or behaviour ever changes, this page will be updated and the effective date above will change with it.
